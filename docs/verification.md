# Simulation & Verification

검증 결과는 **실제 확보한 테스트벤치, 파형, 보드 사진**을 바탕으로 추가합니다.

| 구분 | 확인해야 할 내용 | 상태 |
|---|---|---|
| UART RX/TX | 9600bps, 프레임 수신·송신 | 미검증 |
| RX/TX FIFO | full/empty, 순서·동시 push/pop | 미검증 |
| ASCII Decoder | R/L/U/D/M/S 명령 | 미검증 |
| ASCII Sender | 모드에 맞는 문자열 송신 | 미검증 |
| Watch | 시각 증가 및 설정 | 미검증 |
| Stopwatch | 실행·정지·초기화·모드 | 미검증 |
| HC-SR04 | TRIG/ECHO 거리 환산 | 미검증 |
| DHT11 | 40비트 수신/체크섬·유효값 | 미검증 |
| FND | SW 선택에 따른 표시 | 미검증 |
| top_all | 전체 연결/실보드 검증 | 미검증 |

## 검증 기록 형식

테스트벤치 이름, Vivado 버전, 입력 조건, 예상 출력, 관찰값, 파형 캡처, PASS/FAIL 근거를 함께 남깁니다.

## 현재 빠진 파일

제공받은 원본 ZIP에서는 XDC 및 테스트벤치를 확인하지 못했습니다. 테스트용 파일을 임의로 원본인 것처럼 만들지 않습니다.
